# Prototype (backup)

The exploration prototype of the studio site, kept for reference. The clean rebuild lives on `main`.

- `site/` the Vite + React prototype (`npm install && npm run dev`), including the scroll frames in `site/public/frames`
- `site/film/` the scene script that draws the screen animations and camera paths for the Blender footage
- `blender/` the Blender (Cycles) render pipeline and the three rendered clips in `blender/clips`
- `brand/` the logo kit (SVG, PNG, brand sheet)
- `video/record.js` the script that records the HD walkthrough video
